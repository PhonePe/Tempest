# Support

Tempest is an open-source pre-1.0 project. Community support is provided on a
best-effort basis; no response time, compatibility guarantee, or production
service level is implied.

Use the project issue tracker for reproducible bugs, documentation errors, and
focused feature requests. Before opening an issue:

1. Check the current README, changelog, and existing issues.
2. Reproduce with the latest supported release or development branch.
3. Remove credentials, private keys, internal addresses, customer data, and
   confidential artifacts.
4. Include Tempest version, OS/architecture, configuration with secrets
   redacted, client implementation, requested TFTP options, and focused logs.
5. For protocol issues, include a minimal packet capture when it can be shared
   safely.

Use a discussion rather than a bug report for deployment design, extension API
questions, benchmark methodology, or proposals that need discovery.

Vulnerabilities and suspected security boundary failures must be reported
privately according to [`SECURITY.md`](SECURITY.md). Conduct concerns follow
[`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).

Commercial support, certification, and managed deployment are not provided by
this repository unless announced separately by a maintainer.
